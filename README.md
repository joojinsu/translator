# 📸 EasyOCR 화면 스크린샷 자동 번역기 (Windows)

Python **EasyOCR**과 **글로벌 백그라운드 단축키**를 결합하여, 화면의 임의 영역을 캡처하면 자동으로 글자를 인식(OCR)하고 번역해주는 Windows 애플리케이션입니다.

---

## ✨ 주요 기능

1. **백그라운드 글로벌 단축키 지원**:
   - 프로그램이 최소화되어 있거나 다른 작업(게임, 웹서핑, 문서 작업 등) 중이어도 단축키(`Ctrl + Alt + T` 기본값)를 누르면 즉시 캡처 모드가 실행됩니다.
   - 단축키는 설정 메뉴에서 `F9`, `F10`, `Alt + Q`, `Ctrl + Alt + Z` 등으로 변경 가능합니다.

2. **화면 영역 드래그 캡처 (스니핑 오버레이)**:
   - 단축키를 누르면 화면이 반투명하게 어두워지며, 마우스로 원하는 영역을 사각형으로 드래그하여 정확하게 지정할 수 있습니다. (ESC 키로 취소 가능)

3. **클립보드 스크린샷 자동 번역 (선택 기능)**:
   - 윈도우 기본 캡처 도구(`Win + Shift + S` 또는 `PrtScn`)로 캡처한 이미지가 클립보드에 들어왔을 때 자동으로 인식하여 번역해주는 기능을 켜고 끌 수 있습니다.

4. **EasyOCR 기반 정밀 다국어 인식**:
   - 한국어(Korean) + 영어(English) 기본 탑재
   - 일본어(Japanese), 중국어 간체/번체(Chinese) 모델로 손쉽게 전환 가능
   - PyTorch 딥러닝 기반으로 기울어지거나 작은 글씨도 우수한 인식률 제공

5. **자동 번역 및 결과 팝업창**:
   - 번역 원본/대상 언어 설정 (한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어 등)
   - 원문(OCR 추출 텍스트)과 번역문을 동시에 확인 및 자유롭게 편집 가능
   - **원문 복사**, **번역문 복사**, **수정 후 다시 번역**, **다시 캡처** 원클릭 지원
   - **항상 위에 고정(📌)** 및 **자동 클립보드 복사** 옵션 지원

## 🚀 빠른 시작 (소스로 직접 실행)

### 1. 패키지 설치
```bash
pip install torch torchvision easyocr deep-translator pynput pyperclip pyinstaller pillow
```

### 2. 프로그램 실행
```bash
python app.py
```
> **참고**: 처음 실행 시 EasyOCR 언어 모델 파일이 `~/.EasyOCR/model/`에 자동 다운로드됩니다. (약 1~2분 소요)

---

## 📦 실행 파일(.exe) 빌드 방법

독립 실행 파일로 배포하려면 제공된 빌드 스크립트를 실행합니다:

```bash
python build_exe.py
```

빌드가 완료되면 다음 경로에 실행 파일이 생성됩니다:
- `dist/EasyOCR_Translator/EasyOCR_Translator.exe`

해당 폴더 전체를 압축하거나 바로가기를 만들어 언제든 더블클릭으로 실행할 수 있습니다.

---

## ⚙️ 파일 구성

- `app.py`: 메인 애플리케이션 GUI 및 컨트롤러
- `ocr_engine.py`: EasyOCR 텍스트 인식 및 전처리 엔진
- `translator_engine.py`: Google 번역 및 백업 페일오버 번역 엔진
- `capture_overlay.py`: 고해상도 DPI 대응 반투명 화면 캡처 오버레이
- `hotkey_manager.py`: 백그라운드 글로벌 키보드 후킹 및 클립보드 감지기
- `result_window.py`: 원문/번역문 확인 및 편의 기능 팝업창
- `config.py` & `config.json`: 사용자 설정 저장 모듈
- `build_exe.py`: PyInstaller 자동 빌드 스크립트
